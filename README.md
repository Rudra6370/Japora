# Japora Website

Website for Japora - A modern Jaap Counter application for spiritual practice and mantra counting.

## Website Overview

This website serves as the official online presence for the Japora application, providing:

- **App information** and features
- **Privacy policy** detailing data practices
- **Support & FAQ** for user assistance
- **Contact information** for the developer

## Navigation

- **Home** (`index.html`) - Main app overview with features showcase
- **Features** - Complete list of app features
- **Privacy Policy** (`privacy-policy.html`) - Data practices and compliance
- **Support** (`support.html`) - FAQ and troubleshooting guides
- **Contact** (`contact.html`) - Developer contact information

## Privacy Policy

The full privacy policy is available at `privacy-policy.html`. Key points:

- All user data is stored locally on the device using Hive
- No personal identifiers are collected (name, email, phone)
- Yandex Mobile Ads may collect advertising ID and aggregated usage
- Speech-to-text processes audio locally; no audio retained
- All data remains on the device unless explicitly shared by user
- Users can export/clear all data via app settings

## Features Section

The website showcases these core Japora features with animated counter badges:

1. **Jaap Counting** - 27 counting methods - badge animates when scrolled into view
2. **Multiple Themes** - 8 theme options - badge animates when scrolled into view
3. **Backup & Restore** - 3 backup methods - badge animates when scrolled into view
4. **Games & Sounds** - 2 game/sound categories - badge animates when scrolled into view
5. **Stories & Insights** - 4 scriptural sections - badge animates when scrolled into view
6. **Meditation & Breathing** - 5 breathing modes - badge animates when scrolled into view
7. **Home Screen Widget** - widget feature - badge animates when scrolled into view
8. **Voice Counting** - voice input feature - badge animates when scrolled into view
9. **Sankalp & Counters** - counter management - badge animates when scrolled into view

The feature badges animate from a scaled-down state to full visibility using IntersectionObserver, with numbers counting up from 0 to their respective values.
