Contact

Contact Support

If you need help with Japora, have feedback, or want to report an issue, please use one of the following methods:

In-App Support

The fastest way to get help is through the app. Go to Settings > Feedback to submit your question or report a bug directly from within Japora.

Email

If you cannot access the in-app support, you can email the developer directly.

rudraprakashmajhi@gmail.com

※ Please note: The email address listed is a contact placeholder. For the most responsive support, use the in-app feedback feature.

GitHub Issues

You can also visit the Japora GitHub repository to report issues, view the source code, or contribute to the project.

※ Repository URL will be added when the GitHub repository is created.

Before Contacting Support

  1. Check the Support & FAQ section above for answers to common questions.
  2. Ensure you are using the latest version of the app.
  3. Include your app version and device model when reporting an issue.
  4. For crash reports, enable "Include error logs" in the app settings if available.
